# Отчёт: урок 4 — каталог букетов

## О проекте

Сделан интерактивный каталог-витрина готовых букетов  
**«Конструктор букетов»**.

Категории: Все, Розы, Тюльпаны, Пионы, Микс, Свадебные.

---

## Что реализовано по ТЗ

### Карточка товара
- фото букета
- название
- цена (₸, с форматированием)
- тег статуса («В наличии», «Хит», «Под заказ»)
- рейтинг (★ и число)
- краткое описание (1–2 строки)

### Функции и интерфейс
- **Поиск** по названию и описанию с debounce **400 мс**
- **Табы категорий** с подсветкой активного
- **Адаптивная сетка**: 1 / 2–3 / 3–4 колонки
- **Модальное окно** с подробностями и кнопкой «Быстрый заказ»
- Экран **«Ничего не найдено»** + кнопка **«Сбросить поиск»**

### Дополнительно
- локальные фото букетов (без битых ссылок)
- заглушка с цветочком, если фото не загрузилось
- тонкий розовый скроллбар в стиле сайта (на телефоне скрыт)

---

## Как запустить

```bash
npm install
npm run dev
```

Открыть в браузере ссылку из терминала (обычно `http://localhost:5173`).

---

## Основные файлы

| Файл | Назначение |
|------|------------|
| `index.html` | страница сайта |
| `src/main.js` | логика: поиск, фильтры, модалка |
| `src/data.js` | список букетов |
| `src/style.css` | оформление |
| `public/bouquets/` | фото букетов |

## Итог

Каталог работает по ТЗ: можно искать, фильтровать по категориям, открывать карточку и делать «быстрый заказ».
